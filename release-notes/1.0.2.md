## What's new in 1.0.2

### Changed

- UPDATE shows how far the download has got, e.g.
  "Downloading v1.0.3 · 42% · 40 of 95 MB". When the UPDATE & RESET group is
  closed, its heading shows "downloading 42%".
- Settings is now in five groups. The SUPPORT group (a donation request from
  the original author) is gone; the original author is still credited in the
  README and LICENSE.

### Fixed

- Window positions are kept. The tool panels, the settings window and which
  panels are open are saved about a second after you move, open or close a
  window, so a crash, Task Manager or a Windows shutdown no longer loses them.
  The settings window now remembers its place too.
- At start every window is brought fully back onto a connected screen, so a
  panel left on an unplugged monitor, or hanging off an edge, comes back into
  view.
