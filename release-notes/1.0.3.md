## What's new in 1.0.3

### Changed

- DRAW REGION: draw around the whole signature window (the pin, the number and
  the orange plate) instead of tightly around the digits. A loose box is fine.
  The app finds the pin and the number inside it by itself, trying a few
  frames over half a second. A box around the digits only still works.
- SHOW PREVIEW shows the whole signature window, with the pin outlined in cyan
  and the number being read outlined in green, so you can see at a glance that
  the scanner is locked on the right things.
- When no pin is found the note now reads "No pin icon found in or next to the
  box" and asks you to draw around the whole signature window.
