## What's new in 1.0.1

Citizen Assistant is now **SC Assistant**, and the version number starts again
at 1.0. This is the first published release under the new name.

**Coming from Citizen Assistant 1.2.x?** Install this version by hand once:
quit Citizen Assistant and run SCAssistant-1.0.1-Setup.exe. Because 1.0.1 is a
lower number than 1.2.19, the old UPDATE button will not offer it. Your
settings, notes and inventory move to the new %APPDATA%\SC Assistant folder on
first start, and the old program folder and Start menu entry are removed.
Nothing of yours is deleted. From here on, UPDATE works as usual.

### New

- The scanner shows whether it is following the HUD: TRACKING, SEARCHING or
  FIXED BOX. With SHOW BOX on, the pin and the digits are outlined.
- After DRAW REGION the result is shown for 3 seconds: PIN FOUND — TRACKING ON,
  or NO PIN FOUND — FIXED BOX.
- Ground readings name their minerals: HAND MINING for 3,000-type readings, ROC
  for 4,000-type readings.
- Settings → Hotkeys: change SHOW BAR and HIDE ALL, and give each tool its own
  key.
- Every panel has a push-pin; a pinned panel stays on screen when everything
  else is hidden.
- HAULING, ORE FINDER and COMBAT show how old their data is, and turn amber
  when it is stale.
- DRAW REGION: right-click cancels, hold Ctrl when releasing to fine-tune the
  box with the arrow keys, and a magnifier on high-DPI screens.
- Settings → Update shows what is new in a version before you install it.
- The scanner shows two numbers: SCANNED SIGNATURE (what was just read, on
  every read) and MATCHED SIGNATURE (what the result below is for). The
  reading confidence is now READ NN%, under the matched number.
- The scanner card's border shows the result: green for a match, yellow for a
  number with no match, red when the scan is on screen but cannot be read.
- When a number fits two things, both are shown, e.g. ROC ×19 with
  "or DEBRIS ×38" underneath. Harvestables (plants) are recognised too.
- Readings that match nothing are saved with a small picture, listed under
  Settings → Unmatched readings, so missing signatures can be added.
- Settings → RESET SETTINGS puts the settings back to defaults (click twice).
  Notes, inventory and blueprints are kept, a backup of the old settings is
  made, and the app restarts.
- Settings is in six groups you can open and close (SCANNER, SCAN DATA,
  HOTKEYS, LOOK & SOUND, UPDATE & RESET, SUPPORT); a closed one shows a short
  summary, and the window remembers which ones you left open.

### Changed

- Signature data now comes from scmdb.net, checked at most once a day, with the
  bundled table as a fallback.
- An older box learns the pin by itself from the first signature it reads, and
  again after a resolution change.
- The mining panel is a little wider to fit the tracking status.

### Fixed

- NOTES, INVENTORY and the blueprint registry are never saved over a file that
  could not be read; they show NOT LOADED instead, and the previous save is
  kept as a .bak file.
- UPDATE checks the download against GitHub before installing, and starts the
  old version again if Setup stops.
- The TRACKING slider no longer saves on every pixel of a drag.
- Clearer messages when the pin cannot be found or loaded.
- Large ground fields are recognised: up to 25 ROC deposits, 21 hand-mining
  deposits and 50 pieces of salvage. A 19-deposit Feynmaline field (76,000)
  used to show nothing.
